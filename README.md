# Naipunya Enterprise Service Management

Naipunya is a high-performance Free Asset and IT Management Software package that provides ITIL Service Desk features, licenses tracking, and software auditing.

## Major Features
* **Service Asset and Configuration Management (SACM)**: Manages your IT assets and configurations.
* **Request Fulfillment**: Streamlines request fulfillment processes, making it easy to manage service requests, incidents, and problems.
* **Incident and Problem Management**: Supports efficient handling of Incident Management and Problem Management processes.
* **Change Management**: Enables planning, reviewing, and implementing changes in a controlled and standardized manner.
* **Knowledge Management**: Includes a knowledge base and FAQ support.
* **Contract Management**: Aligns with Supplier Management processes.
* **Financial Management for IT Services**: Assists in managing financial information, purchase orders, warranties, and depreciation.
* **Asset Reservation**: Allows reserving IT assets for specific purposes or periods.
* **Data Center Infrastructure Management (DCIM)**: Management of racks and data center assets.

## Prerequisites
* A web server (Apache, Nginx, IIS, etc.)
* MariaDB >= 10.6 or MySQL >= 8.0
* PHP >= 8.2
